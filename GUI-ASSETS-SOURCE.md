# GUI из VK_2_0.ipa

Источник: файл пользователя `../VK_2_0.ipa`, изображения из `Payload/vkclient.app/`. Выбран старый объёмный набор без префикса `7_`. Исполняемый файл, код, Info.plist, логотипы, AppIcon и LaunchImage из IPA не импортировались. Собственная иконка, Avatar, фон входа и splash сохранены.

Импортировано 48 пар обычных/Retina изображений. Точная карта исходных имён, размеров и SHA-256 — tools/vk-ipa-assets.json. Обновлены панели навигации, кнопки и возврат назад, значки бокового меню, элементы профиля, пузыри сообщений, поле/панель отправки, кнопка отправки, поля входа, кнопка входа, значки комментариев и отметок, четыре кнопки музыкального плеера.

Apple CgBI PNG декодированы из BGRA с premultiplied alpha в стандартный RGBA PNG. Области растяжения адаптированы к исходным размерам; значок меню получает белый цвет при рисовании, а небольшие значки постов — акцент темы в тёмном режиме. Альфа-маски берутся из оригинальных изображений.

Повторить импорт: `python3 tools/import_vk_ipa_assets.py` (Pillow, исходный IPA рядом с папкой проекта). Для сборки Xcode ни Pillow, ни IPA не нужны — PNG уже включены в проект. Не запускайте старые генераторы chrome поверх этого импорта. Нативное размещение и cap insets требуют проверки на iOS 6/iPad.

Для «Ответов» и «Групп» добавлены ещё три пары: left_answers, left_groups и group_placeholder_50px. Всего импортировано 51 пара; карта и хеши обновлены. Визуальные ориентиры и методы API перечислены в SOCIAL-REFERENCES.md.
