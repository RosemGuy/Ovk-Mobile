# Оптимизация и размеры GUI

Изменения в этой ревизии:

- Совпадающие запросы изображений объединяются по URL, размеру декодирования и поколению кэша. Несколько ячеек получают один результат; отмена одной подписки не отменяет остальных. Последняя отмена останавливает общий запрос. Декодирование остаётся вне главного потока, существующие ограничения кэша для 512 МиБ / 1 ГБ сохранены.
- Меню переиспользует ячейки. Порядок и отфильтрованный список пунктов кэшируются и сбрасываются при соответствующих изменениях. Тонированный значок меню рисуется один раз.
- Растягиваемые изображения GUI кэшируются; кэш сбрасывается при смене цвета/темы и предупреждении о памяти. Фоны ячеек и значки галочек переиспользуются.
- Неизменившийся текст пузыря сообщения не измеряется повторно при каждой раскладке. Скрытые дополнительные картинки вне ленты не скачиваются.
- Сканирование локальной музыки перенесено с главного потока. Параллельные сканирования не запускаются; при импорте во время сканирования выполняется повтор. Неизменившийся список не перезагружается.
- В аудиоплеере строка времени меняется при смене секунды; повтор, shuffle, play/pause и доступность переходов перерисовываются при изменении состояния. Ползунок продолжает плавно обновляться с прежним интервалом.

Подгон оригинальных ассетов:

| Элемент | Размер/правило |
| --- | --- |
| Панель меню | строка 45 pt (прежняя подсветка), исходный PNG иконки 31×31 pt без сжатия; координаты выровнены по пикселям |
| Серая/синяя кнопка | исходная высота 33 pt, верх/низ растяжения 15/15 pt |
| Счётчик профиля | исходная высота 46 pt, пересчитаны строки и положение фотографий |
| Заголовок поста | 54 pt по исходному news_post_header; пересчитан отступ текста/высота записи |
| Поля входа / кнопка входа | 44 / 46 pt |
| Сообщения | поле 41 pt, рисунок отправки 29 pt внутри области нажатия 44 pt; хвосты пузырей не растягиваются |
| Фон профиля/группы | повторяемый фрагмент 64×64 pt исходного wall_background, без масштабирования текстуры на весь экран |

ChromeCaps.json — единая карта областей растяжения. tools/test_chrome_caps.py сверяет её с обычными/Retina PNG и хешами импортированных файлов. Добавлены оригинальные black_btn_nav_hl и wall_background из пользовательской IPA; для последнего в манифесте записан crop. Всего импортировано 53 пары.

Проверены здесь: структура проекта, области растяжения и пары Retina, хеши 106 импортированных PNG, расчёт геометрии плеера/коллажей, логика выбора архитектур IPA-скрипта.

Нативный тест tools/TestImageRequests.command проверяет объединение запросов, отдельную отмену, последнюю отмену, поздний ответ, синхронную ошибку, повтор и разные размеры декодирования. Он требует OS X/Apple SDK и в Linux не запускался.

Реальный FPS, время запуска и пик памяти пока не измерены. Для сравнения на iPod touch 4 и iPhone 5s нужна Release-сборка на том же устройстве и том же наборе записей. Проверить холодный запуск, несколько страниц ленты с повторяющимися аватарами, большой чат, локальную медиатеку, смену темы и возврат из fullscreen. Сеть и подготовка видео могут влиять на время открытия независимо от раскладки GUI.
