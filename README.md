# Ovk-Mobile

Неофициальный клиент **OpenVK для iOS 6** с объёмным интерфейсом, локальной музыкой и поддержкой нескольких аккаунтов.

**Статус: alpha · Версия: 1.0**

## Возможности

- Вход на openvk.xyz, openvk.org или свой инстанс, отдельный API-домен и 2FA.
- Добавление и переключение аккаунтов разных инстансов.
- Новости, профили, друзья, диалоги и отправка текстовых сообщений.
- Публикация записей, комментарии и ответы.
- Постановка и снятие лайков.
- Меню записи по долгому нажатию: архивировать, вернуть на стену, удалить, закрепить, открепить или поделиться ссылкой. Доступность зависит от прав аккаунта.
- Просмотр архива записей, фотографий и вложений.
- Музыка OpenVK и локальные аудиофайлы, фоновое воспроизведение и управление с экрана блокировки.
- Экспериментальный просмотр видео.
- Светлая и тёмная темы, шесть цветовых акцентов, крупный текст и настройка порядка меню.
- Русский и английский интерфейс.
- Постоянная боковая панель на iPad и поддержка обеих ориентаций.

В **Настройки → версия приложения** находится экран «Об приложении». У логотипа есть секрет по долгому нажатию.

## Требования

| Компонент | Требование |
| --- | --- |
| Система устройства | iOS 6.0 и новее с поддержкой 32-битных приложений |
| Архитектуры сборки | armv7 / armv7s |
| Среда разработки | Xcode 5.1.1, OS X 10.9 |
| Проект и схема | `OpenVKClassic.xcodeproj` → `OpenVKClassic` |

Для iPod touch 4 и устройств с объёмом памяти до 512 МиБ автоматически применяется экономный профиль: уменьшенные изображения и кэш, последовательное декодирование и меньшие страницы загрузки. Обработка JSON выполняется в фоне. Скорость на конкретном устройстве нужно проверять отдельно.

## Сборка

```sh
git clone https://github.com/RosemGuy/Ovk-Mobile.git
cd Ovk-Mobile
open OpenVKClassic.xcodeproj
```

В Xcode выберите схему **OpenVKClassic** и нужный симулятор, затем нажмите **Run**. Собирать нужно в гостевой OS X, если используется виртуальная машина.

### IPA для устройства с джейлбрейком

В терминале OS X из папки проекта:

```sh
bash BuildIPA.command
```

Готовый файл: **`dist/Ovk-Mobile-alpha.ipa`**.

Скрипт выполняет сборку для устройства и ad-hoc подпись. Для установки такой IPA требуется AppSync либо другой совместимый механизм подписи на устройстве с джейлбрейком. Установка без джейлбрейка требует собственного сертификата и provisioning profile.

Если сборка завершилась ошибкой, откройте **`Build-result.txt`**. Полный лог — **`build-ipa.log`**. Не используйте `.app` из симулятора для упаковки IPA устройства.

## Аккаунты и музыка

**Аккаунты:** Настройки → Аккаунты. Добавление сохраняет остальные сеансы; пункт «Выйти» удаляет текущий аккаунт с устройства. Закрытие приложения сеансы не удаляет.

Токены сохраняются в Keychain. При некоторых отказах Keychain на iOS используется закрытая папка приложения с `NSFileProtectionComplete`, правами файла `0600` и исключением из резервной копии. Резервное сохранение допускается только при доступных защищённых данных. Пароли не сохраняются.

**Локальная музыка:** раздел Музыка → На устройстве. Передавайте файлы через iTunes File Sharing или «Открыть в Ovk-Mobile». Поддержка MP3, AAC/M4A, WAV, CAF и AIFF зависит от системного декодера. Локальная музыка доступна и без входа в OpenVK.

**Музыка сервера:** вкладка OpenVK в разделе Музыка. Экспериментальный переключатель нужен только для видео.

## Ограничения alpha

- Работа API, рейтинга и действий с постами зависит от версии и настроек инстанса.
- Старые версии iOS могут не поддерживать сертификаты, защитные страницы или кодеки сервера. Проверка TLS не отключается.
- Серверные аудио и видео сначала скачиваются целиком. Потокового воспроизведения и универсального декодера FFmpeg/VLC нет.
- Загрузка собственных фото и видео на сервер пока не реализована. Редактор отправляет текст.
- Реальное сохранение входа, фоновый звук, видео и производительность требуют проверки на устройстве. Автоматические проверки проекта не заменяют сборку в Xcode.

## Проверки и документация

Проверки без Apple SDK:

```sh
python3 tools/validate_project.py
python3 tools/test_build_ipa.py
bash tools/TestAudioDuration.command
bash tools/TestFeedLayout.command
bash tools/TestMediaFormat.command
```

`test_build_ipa.py` использует имитацию инструментов Apple и не компилирует iOS-приложение. Дополнительные нативные тесты в `tools/Test*.command` запускаются в OS X.
