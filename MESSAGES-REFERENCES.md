# Сообщения старого VK

Основной визуальный ориентир — [скриншот списка диалогов и чата](https://cdn.iphones.ru/wp-content/uploads/2023/10/11-22-1241x725.jpg), который пользователь уже предоставил в Pictures/oldvk. [Публикация с архивом интерфейсов](https://www.iphones.ru/iNotes/vk-ispolnilos-17-let--kak-menyalsya-dizayn-kazhdyy-god-i-chto-segodnya-tam-est-10-06-2023) содержит этот материал в разделе о старом клиенте. Поиск также выдаёт плоский VK 2016 года и концепты Behance; они не используются вместо исходников из IPA.

В предоставленной VK_2_0.ipa найдены:

| Исходное имя | Использование |
| --- | --- |
| Grey_Bubble / Blue_Bubble | входящие и исходящие пузыри |
| Grey_Bubble_Selected / Blue_Bubble_Selected | нажатое состояние пузырей |
| MessageEntryBackground | панель ввода |
| MessageEntryInputField | поле сообщения |
| send_button / send_button_hl | обычная и нажатая кнопка отправки |
| left_badge | оригинальный фон счётчика непрочитанного |
| MessagesGroup | значок групповой беседы рядом с названием |
| group_placeholder_50px | заглушка аватара сообщества/беседы |

messages_check / messages_unchecked — кружки выбора сообщений для режима редактирования. Они не используются как выдуманный индикатор доставки или прочтения.

В клиенте: квадратные аватары 50 pt в списке, компактный текст последнего сообщения, миниатюра отправителя при наличии его фотографии, подсветка непрочитанного, счётчик на оригинальном фоне. В личной переписке без аватара у каждой реплики, короткие пузыри, время снаружи; в групповой беседе входящий аватар сохраняется. Поле/панель отправки используют ранее импортированные оригиналы и область нажатия 44 pt. Все новые PNG импортируются из IPA с CgBI-декодированием; соответствие и SHA-256 находятся в tools/vk-ipa-assets.json.

Подсветка бокового меню возвращена к прежнему отображению целого menu_cell_hl (с цветом темы), без растягивания центральной полосы. Оптимизации повторного использования ячеек и загрузок изображений сохранены.

Это адаптация по оригинальным ресурсам и доступным скриншотам, а не проверенный снимок приложения. Нативный результат нужно проверить в Xcode на iOS 6 и iPad.
